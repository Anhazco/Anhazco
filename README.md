# Hola, soy Cristian Añazco 👋

**Software para gestionar información y procesos. Desde Paraguay 🇵🇾**

En este perfil comparto mis proyectos de desarrollo de software, con aplicaciones orientadas a la gestión ganadera y al seguimiento de convenios institucionales.

## Proyectos destacados

### [GENSYS · Gestión ganadera](https://github.com/Anhazco/GENSYS)

Aplicación de gestión ganadera con una API en **C# y ASP.NET Core 8** y una interfaz web que utiliza **Astro, React, TypeScript y Tailwind CSS**.

El backend está organizado en capas de dominio, aplicación, infraestructura y API.

[Explorar el código →](https://github.com/Anhazco/GENSYS)

### [GestCon · Gestión de convenios](https://github.com/Anhazco/GestCon_Anhazco)

Sistema en **Java** orientado al control y seguimiento de acuerdos entre universidades e instituciones, con una administración centralizada de los convenios.

[Explorar el código →](https://github.com/Anhazco/GestCon_Anhazco)
