## 🚀 Proyectos Destacados

### 🐂 [GENSYS · Sistema de Gestión Ganadera](https://github.com/Anhazco/GENSYS)
> Plataforma web integral diseñada para la gestión, control sanitario, reproducción, movimientos y pesajes de rodeos bovinos.

- **Arquitectura:** Arquitectura Limpia por capas (*Domain, Application, Infrastructure, API*).
- **Stack:**
  - **Backend:** C#, .NET 8, ASP.NET Core, Entity Framework Core, SQL Server.
  - **Frontend:** Astro 5, React 19, TypeScript, Tailwind CSS 4, TanStack Query, Chart.js.
  - **Documentación:** Swagger / OpenAPI & VitePress.
- 🔗 **[Explorar el código fuente de GENSYS →](https://github.com/Anhazco/GENSYS)**

<br>

### 📑 [GestCon · Sistema de Gestión de Convenios](https://github.com/Anhazco/GestCon_Anhazco)
> Aplicación de escritorio orientada a la centralización, fiscalización y seguimiento de convenios entre universidades e instituciones.

- **Funcionalidades:** Búsquedas especializadas, gestión de entidades y unidades académicas, control de firmantes y generación de reportes e informes.
- **Stack:**
  - **Lenguaje & UI:** Java 8, Java Swing.
  - **Persistencia & Datos:** Hibernate 5.2, JPA, PostgreSQL.
  - **Informes:** JasperReports 6.3.
- 🔗 **[Explorar el código fuente de GestCon →](https://github.com/Anhazco/GestCon_Anhazco)**
